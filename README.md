# Tea Business Launch Control

30-day launch execution control room for the tea business.

## Included
- 30 execution tasks
- Owner, deadline, dependency, cost, status and Go/No-Go
- Search and filters
- Progress dashboard
- Browser localStorage persistence
- Mobile-friendly UI
- No backend or API cost

## GitHub Pages
Go to **Settings → Pages → Deploy from branch → main → / (root) → Save**.

Site URL:
https://anupdavin.github.io/tea-business-launch-control/

Task changes are saved in the browser's localStorage.

## Launch rule
Do not mark a launch gate Go without evidence from actual validation, unit economics, compliance, or dry-run operations.
